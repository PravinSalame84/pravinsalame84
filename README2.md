# Pravin Salame — Portfolio

Premium animated React portfolio starter for `pravinsalame84.github.io`.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this project to a **new** GitHub repository (do not use `pravinsalame84.github.io`).
2. In Vercel, choose **Add New → Project** and import the new repository.
3. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
4. Deploy. Vercel will provide a `.vercel.app` preview URL and can redeploy on future pushes.

## Before launch

- Verify the portrait URL and replace it with a local image in `public/` if preferred.
- Add a real resume PDF to `public/` and add a Resume button if desired.
- Confirm the descriptions and links for all projects.
- Add a contact form only if you choose a form provider; the current contact links use email.
